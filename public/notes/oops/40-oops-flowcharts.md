║                                            │                                                ║

║           count++;                                                                          ║

### Association, Aggregation, Composition

```

║                                                                                             ║
║                      ASSOCIATION --> AGGREGATION --> COMPOSITION                            ║

║                                                                                             ║
╠═════════════════════════════════════════════════════════════════════════════════════════════╣

║  ╔═════════════════════════════════════════════════════════════════════════════════════╗    ║
║  ║                                                                                     ║    ║
║  ║                         ASSOCIATION (General "uses")                                ║    ║
║  ║                                                                                     ║    ║
║  ║        ╔════════════╗               knows               ╔════════════╗              ║    ║
║  ║        ║  Teacher   ║ --------------------------------- ║  Student   ║              ║    ║
║  ║        ╚════════════╝                                   ╚════════════╝              ║    ║
║  ║                                                                                     ║    ║
║  ║        * Both exist independently                                                   ║    ║
║  ║        * Loosest relationship                                                       ║    ║
║  ║                                                                                     ║    ║
║  ╚═════════════════════════════════════════════════════════════════════════════════════╝    ║
║                                                                                             ║
║  ╔═════════════════════════════════════════════════════════════════════════════════════╗    ║
║  ║                                                                                     ║    ║
║  ║                    AGGREGATION (Weak HAS-A, can exist separately)                   ║    ║
║  ║                                                                                     ║    ║
║  ║        ╔════════════╗                has               ╔════════════╗               ║    ║
║  ║        ║ Department ║ <>------------------------------ ║  Employee  ║               ║    ║

║  ║                                                                                     ║    ║
║  ║        * Employee CAN exist without Department                                      ║    ║

║  ║                                                                                     ║    ║
║  ║        class Department {                                                           ║    ║
║  ║            List<Employee> employees;     // Reference only, not created here        ║    ║

║  ║                                                                                     ║    ║

║  ╔═════════════════════════════════════════════════════════════════════════════════════╗    ║
║  ║                                                                                     ║    ║
║  ║                   COMPOSITION (Strong HAS-A, lifecycle dependent)                   ║    ║
║  ║                                                                                     ║    ║
║  ║        ╔════════════╗               owns               ╔════════════╗               ║    ║
║  ║        ║   House    ║ <*>----------------------------- ║    Room    ║               ║    ║

║  ║        * Room CANNOT exist without House                                            ║    ║
║  ║        * House deleted --> Room also deleted                                        ║    ║
║  ║        * Filled diamond (<*>)                                                       ║    ║
║  ║                                                                                     ║    ║
║  ║        class House {                                                                ║    ║
║  ║            private Room room = new Room();   // Created inside, owned               ║    ║

║                                                                                             ║

║                                                                                             ║
║                              STRENGTH COMPARISON                                            ║
║                                                                                             ║
║     Association -------------- Aggregation -------------- Composition                       ║
║        (Weak)                   (Medium)                   (Strong)                         ║
║                                                                                             ║
║     * Uses                     * Has (can share)          * Owns (exclusive)                ║

║     * No ownership             * Shared ownership         * Full ownership                  ║
║                                                                                             ║
╚═════════════════════════════════════════════════════════════════════════════════════════════╝

║          (no memory)               ║  Inheritance   = Code reuse + extends + IS-A           ║
║  Object = Instance, Real entity    ║  Polymorphism  = Overloading + Overriding              ║
║          (has memory in heap)      ║  Abstraction   = abstract class + interface            ║
║                                    ║                                                        ║
╠════════════════════════════════════╬════════════════════════════════════════════════════════╣
║                                    ║                                                        ║
║  KEYWORDS                          ║  RELATIONSHIPS                                         ║
║  --------------------------------  ║  ------------------------------------------------      ║
║  this   = Current object ref       ║  IS-A        = Inheritance (Dog IS-A Animal)           ║
║  super  = Parent class ref         ║  HAS-A       = Composition/Aggregation                 ║
║  static = Belongs to class         ║  Association = General (Teacher-Student)               ║
║  final  = Cannot change            ║  Aggregation = Weak HAS-A (can exist alone)            ║
║  abstract = No implementation      ║  Composition = Strong HAS-A (lifecycle tied)           ║
║                                    ║                                                        ║
╠════════════════════════════════════╬════════════════════════════════════════════════════════╣
║                                    ║                                                        ║
║  OVERLOADING vs OVERRIDING         ║  ABSTRACT CLASS vs INTERFACE                           ║
║  --------------------------------  ║  ------------------------------------------------      ║
║  Overloading:                      ║  Abstract Class:                                       ║
║    * Same class                    ║    * extends keyword                                   ║
║    * Same name                     ║    * 0-100% abstraction                                ║
║    * Different params              ║    * Has constructors                                  ║
║    * Compile-time                  ║    * Any access modifier                               ║
║                                    ║                                                        ║
║  Overriding:                       ║  Interface:                                            ║
║    * Parent-Child class            ║    * implements keyword                                ║
║    * Same signature                ║    * 100% abstraction (pre-Java 8)                     ║
║    * Runtime polymorphism          ║    * No constructors                                   ║
║                                    ║    * Multiple inheritance OK                           ║
║                                    ║                                                        ║
╠════════════════════════════════════╩════════════════════════════════════════════════════════╣
║                                                                                             ║
║                                     GOLDEN RULES                                            ║
║                                                                                             ║
║  1. Favor Composition over Inheritance                                                      ║
║  2. Program to Interface, not Implementation                                                ║
║  3. Encapsulate what varies                                                                 ║
║  4. Single Responsibility - One class, one purpose                                          ║
║  5. Open/Closed - Open for extension, closed for modification                               ║
║                                                                                             ║
╚═════════════════════════════════════════════════════════════════════════════════════════════╝
```
